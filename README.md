# Supply Chain Analytics | SQL & Power BI

## Project Overview

This project analyzes supply chain operations using **PostgreSQL and Microsoft Power BI**. It explores product sales, revenue generation, inventory levels, supplier performance, shipping efficiency, manufacturing costs, and product quality.

The goal is to turn supply chain data into meaningful insights that can support business decisions and operational improvements.

## Tools & Technologies

- **PostgreSQL** — Data analysis, aggregations, filtering, ranking, and SQL views
- **Microsoft Power BI** — Interactive dashboard development and data visualization
- **CSV** — Dataset storage and data import

## Dataset

The dataset contains **100 records and 24 columns**, covering:

- Product information: product type, SKU, price, and availability
- Sales: quantity sold and revenue generated
- Inventory: stock levels and order quantities
- Suppliers: supplier names, locations, and lead times
- Shipping: carriers, transportation modes, routes, shipping times, and costs
- Manufacturing: production volumes, manufacturing lead times, and costs
- Quality control: inspection results and defect rates

## SQL Analysis

The SQL queries explore the following business questions:

1. **Data validation:** Check record counts, missing values, and duplicate SKUs.
2. **Sales and revenue:** Calculate total revenue, units sold, and average product prices.
3. **Product performance:** Compare revenue and sales across product categories.
4. **Supplier analysis:** Compare revenue generated by suppliers.
5. **Geographical analysis:** Analyze revenue and sales across locations.
6. **Shipping performance:** Compare shipping carriers, costs, and delivery times.
7. **Inventory management:** Identify low-stock products and classify inventory levels.
8. **Quality control:** Analyze inspection outcomes and products with higher defect rates.
9. **Advanced SQL:** Use common table expressions, subqueries, window functions, `RANK()`, and `CASE` expressions.
10. **SQL views:** Create `vw_supply_chain_analysis` with additional stock and defect classifications.

## How to Run the Project

### 1. Set up the database

- Install PostgreSQL and open pgAdmin or another PostgreSQL client.
- Create a database for the project.
- Import `supply_chain_data.csv` into a table named `supply_chain`, matching the column names and data types.

### 2. Run the SQL queries

- Open `supply_chain.sql` in your SQL editor.
- Run the table creation statement only if the table does not already exist.
- Execute the analysis queries to explore the data.
- Review the SQL view after creating it.

### 3. Open the Power BI report

- Install Microsoft Power BI Desktop.
- Download and open the `.pbix` file.
- If prompted, update the data source settings to point to your local dataset or PostgreSQL database.
- Refresh the report if required.
